Visual Nerve local API

Connect tools to the diagrams in your browser. The optional local bridge gives API and MCP clients access to the same workspace you edit on the canvas.

Set up API & MCP ↗ Download OpenAPI

Your browser owns the data

Diagrams stay in local IndexedDB. The bridge forwards commands to your connected browser and does not store application records.

You choose the access

In Settings, enable Read only or Read + write for MCP access. Access is off by default; changes require write permission.

The same model everywhere

Diagrams, code and SQL imports, 3D views, playback and process simulations use the same model through the UI, API and MCP.

This public reference cannot send commands. To use the endpoints, start the bridge on your computer and connect it in Settings.
