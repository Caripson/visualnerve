## How to use these guides

Each guide explains what the feature does, where to find it, the steps to try, how to read the result and what to check if it goes wrong. Use **Search help** for a label, a task or a format; it searches this documentation locally. **On this page** jumps to a specific procedure. Select a screenshot to inspect it at its full size.

Screenshots show the real tool with illustrative data. Button names match the English interface. On a phone, use **Projects** to open diagrams, **Edit** for selected object properties and **Diagram actions** for the longer tool menu. The same saved diagram and settings apply in every view.

## Keep your work safe

**Saved** means the change is stored in this browser profile at this website address. There is no automatic account, cloud copy or synchronization between devices. Export a full backup regularly, and before clearing site data. See [local storage and settings](/help/settings/#export-all-local-data).
