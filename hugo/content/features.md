## Draw a system you can keep editing

Start with a mind map, flowchart, timeline, customer journey, process map, responsibility flow or system architecture. Objects and connections remain editable: name the steps, explain the relationships, choose icons and colors, and assign owners and statuses.

Use groups, collapsed branches, search and filters to keep a large diagram readable. Add a drawing layer for annotations without changing the graph. On a phone, Projects, Edit and Diagram actions open temporary panels around the canvas.

![A customer onboarding diagram with a selected object and its editable properties.](/help/images/editor.webp "Objects have descriptions, responsibility and status as well as a position on the canvas.")

[Learn the editing controls](/help/editing/)

## Turn rows into a useful visual question

Import a CSV, clean columns, filter rows, choose grouping levels and calculate counts, sums, averages, medians or other measures. A large source can become a small, connected view of customers, regions or products.

Original cells remain available. Explain a measure using its contributing rows, investigate data quality, connect files through explicit matching keys and review a source refresh before applying it. Named analysis views let you return to another perspective over shared source data.

Displaying fewer groups does not reduce the rows used in a measure. The current limits include 200,000 rows per source and 600 generated objects per view; structural and file-size limits still apply.

![CSV analysis controls with cleanup, filters, grouping and measures.](/help/images/csv-import.webp "Choose the question and the level of detail before creating the data diagram.")

## Read SQL and source code as connected structure

SQL SELECT and WITH queries reveal source aliases, joins, output expressions and column lineage. Table definitions reveal columns, keys and foreign-key relationships. SQL is analyzed locally and never executed.

Code import covers 50 languages with bounded structural analyzers. Start with a file overview or separate declarations, then inspect dependency evidence and confidence. Recognized calls can be heuristic or unresolved; the diagram is a reading aid, not a compiler or runtime debugger.

Existing `.drawio` and `.vsdx` files can also become editable native diagrams. Preview pages and import notes before choosing the page to create. Advanced shapes and routing may be simplified.

## Keep a readable overview while exploring depth

Switch the same styled objects and connections between 2D and 3D. In 3D, cards have relief and readable front and back faces. Rotate the view, focus a region and move selected objects while retaining a useful 2D arrangement.

Semantic overview can summarize a larger graph without replacing its original objects. Relationship questions show modeled paths with source evidence. Named snapshots let you review changes before restoring earlier diagram content.

## Explore the workspace on your phone

On a smaller screen, **Projects** opens the diagram list, **Edit** opens the selected object's properties, and **Diagram actions** brings the advanced tools into reach. These temporary panels leave more room for the canvas when you close them.

![Visual Nerve's mobile workspace with compact diagram controls.](/site/images/phone.webp "The phone view keeps the diagram visible, with project navigation and editing tools close at hand.")

Use a desktop for large imports, detailed model configuration and broad comparisons. Work stays in the browser profile and website origin where you created it; opening a phone does not automatically synchronize a laptop's workspace. Export and restore a copy when moving between devices.

[Follow the mobile navigation guide](/help/getting-started/#find-your-way-around)

## Explain the diagram as a walkthrough

Number objects or author storyboard scenes with their own narration, duration and saved view. Play the sequence with optional subtitles and local English or Swedish narration. Alan, a British male voice, is the English default.

Minimize the player to keep the canvas visible. Preload prepares upcoming audio. Export the sequence as a 720p, 30 fps video, with MP4 preferred and WebM used where supported. Voice assets need an initial download; narration is then generated locally. Export limits and codec support are explicit.

[Create a presentation](/help/presentations/)

## Test assumptions about work and capacity

Process Simulator is a separate template for arrivals, queues, processing, shared resources, routing, scaling and economics. Particles represent actual simulated work. Compare scenarios to see how a capacity change affects waiting, throughput, lost work, revenue and cost across the system.

The UI, local API and MCP use the same seeded simulation engine. An animated run and a MAX run with the same inputs produce the same business result.

[Explore Process Simulator](/process-simulator/)

## Keep and share the right kind of copy

PNG and PDF share the 2D visual view. Markdown shares a semantic outline. Native JSON preserves a diagram, and a complete workspace backup includes the wider local data needed for recovery.

Build with Lovable prepares a reviewed app specification and prompt locally. Opening its dialog sends nothing; choosing Open in Lovable explicitly shares the reviewed text. Review descriptions, SQL literals and other included detail before that handoff.

The workspace belongs to one browser profile and origin. There is no automatic cloud synchronization or simultaneous team editing. Use exports and backups to move or share a copy.
